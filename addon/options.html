Music Assistant settings

Firefox encrypts these before they leave this device. They reach only Firefox installs signed in to the same Firefox account with add-on data sync turned on.

Make the token in Music Assistant, not Home Assistant: Settings > Profile > Long-lived access tokens. Signing in to Music Assistant through Home Assistant is fine. The account must be an admin, because changing YouTube Music's sign-in needs admin. The token lasts one year.

Anyone using this Firefox profile can use the token.

Away from home, use an address your phone can reach from outside.
